\# Project Evidence



\## Overview



This folder contains evidence collected during the implementation and verification of the Windows Firewall Configuration and System Hardening project.



The evidence demonstrates that the security configurations were successfully implemented and validated.



\---



\## Evidence Collected



\### Firewall Configuration



\- Windows Defender Firewall enabled

\- Domain Profile enabled

\- Private Profile enabled

\- Public Profile enabled



\---



\### Custom Firewall Rules



The following firewall rules were successfully created:



| Rule Name | Action |

|------------|--------|

| CG\_HTTP\_Allow | Allow |

| CG\_HTTPS\_Allow | Allow |

| CG\_SSH\_Allow | Allow |

| CG\_FTP\_Block | Block |

| CG\_Telnet\_Block | Block |
